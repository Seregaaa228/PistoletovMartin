FRONTIER NATIONS 0.4.0 — СБОРКА ДЛЯ ИГРОКОВ

Minecraft Java 1.20.1 • Forge 47.4.0 • Java 17
Внутри все 27 модов актуальной сборки, настройки и набор оружия TaCZ.
Есть новые заводы, строительство NPC, исследования стран, авиация и единый стиль техники.

УСТАНОВКА
1. Распакуй весь ZIP в отдельную папку.
2. В лаунчере установи Minecraft 1.20.1 с Forge 47.4.0 и выбери Java 17.
   Установщик Forge лежит в installers. Перед его использованием запусти обычную
   Minecraft 1.20.1 один раз; затем открой JAR и выбери Install client.
   Для первого скачивания игры и библиотек понадобится интернет.
3. Укажи в профиле лаунчера папку игры: game из распакованного архива.
   Если лаунчер не позволяет выбрать папку, создай чистый профиль этой версии
   Forge, открой его игровую папку и скопируй туда СОДЕРЖИМОЕ папки game.
   В mods этого профиля должны находиться только 27 JAR из данного архива.
4. Выдели игре 4–6 ГБ памяти, запусти профиль Forge и подключись к адресу сервера,
   который даст организатор. Это клиентская сборка, готовый сервер сюда не входит.

КАК НАЧАТЬ
КПК → ПКМ по воздуху → «Заводы» → «Комплекты зданий».
Найми строителя за 4 изумруда, возьми комплект и поставь площадку на ровную землю.
Электростанция → подстанция → заводы и исследовательский центр.
ПКМ по встроенному планшету здания открывает его управление.
До производства новой техники/ПВО нужны исследования страны.
Подробности — docs/ПРОМЫШЛЕННОСТЬ.md, остальные руководства тоже в docs.

Это новый отдельный клиентский профиль. Карты, сохранения, серверные адреса,
учётные записи, токены и настройки лаунчера владельца сборки не включены.
Модели и текстуры встроены в моды; отдельный ресурс-пак не требуется.
Состав модов и контрольные суммы находятся в MODS.json и FILES-SHA256.json.
Исходники собственных дополнений и сведения об авторах находятся в sources и licenses.
