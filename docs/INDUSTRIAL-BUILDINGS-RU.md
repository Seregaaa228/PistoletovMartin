# Промышленные здания: установка и проверка

Для Minecraft 1.20.1, Forge 47.4.0 и Java 17. В Industry включены семь
объектов: электростанция, подстанция, четыре завода и исследовательский центр.
Заводы содержат склады; оружейный завод использует модели оружия из TaCZ.

Для новых зданий необходимы четыре сторонних мода. Их JAR не входят в Git;
точные версии, ссылки и SHA-256 записаны в `buildings-dependencies.lock.json`:

- [Engineer's Decor Ported 1.3.31](https://www.curseforge.com/minecraft/mc-mods/engineers-decor-ported/files/5817392);
- [Another Furniture 3.0.4](https://www.curseforge.com/minecraft/mc-mods/another-furniture/files/7131795);
- [WarStuff II 1.2.8](https://www.curseforge.com/minecraft/mc-mods/warstuff-decorations/files/6238871);
- [WarStuff Legacy 1.0.5](https://www.curseforge.com/minecraft/mc-mods/warstuff-legacy/files/6168019).

Загрузите закреплённые файлы с проверкой контрольных сумм и соберите отдельный
профиль, следуя общим инструкциям по подготовке зависимостей проекта:

```powershell
python tools/fetch_integrations.py
python tools/building_dependencies.py
python tools/build.py
python tools/create_test_profile.py build/factory-test-profile
```

Укажите новый каталог как игровую директорию в лаунчере Forge. Для сервера
используйте те же версии необходимых модов. `--baseline` создаёт исходный
профиль и не добавляет новые здания. Не кладите JAR сторонних модов в Git.

Контейнеры готовой продукции хранят содержимое раздельно. Центральный блок
показывает по пять контейнеров на странице; стрелки переключают страницы.
Старые запасы отображаются отдельно, если они есть. Предметы выдаются через
терминал владельцу объекта. Отсутствующие контейнеры не считаются свободной
ёмкостью; их оставшееся содержимое можно забрать через центральный блок.
Пустые контейнеры в выгруженных чанках становятся видимы при повторном открытии
после загрузки соответствующих чанков. Одна стопка может распределяться между
несколькими частично заполненными контейнерами.

Шаблоны существующих объектов версий 1–15 не заменяются автоматически;
новые используют версию 16 и поворот при размещении. Перед обновлением рабочего
мира сохраните его резервную копию. Клиентскую проверку моделей TaCZ,
текстур, ориентации предметов и оформления нужно проводить отдельно в свежем
тестовом мире; успешная сборка или серверные тесты не проверяют отрисовку.
