# Дальность видимости техники и ракет

Коротко: чтобы видеть самолёты/наземную технику/ракеты издалека без "тумана" и
попапа, а не только дальний рельеф — три независимых рычага, и они не
взаимозаменяемы.

## 1. Server view-distance ≠ clientTrackingRange

`clientTrackingRange()` в коде (в чанках) — это *потолок*, не гарантия.
Реальная видимость сущности = `min(clientTrackingRange, view-distance сервера)`.
У техники в этом проекте диапазон и так уже широкий (SBW: 512 чанков у техники,
64 у снарядов; DeepStrike: 128; Industry после этой правки: 32) — почти всегда
упирается именно в view-distance сервера, а не в код.

- **В одиночной игре** view-distance сервера = ваш клиентский `renderDistance`
  (интегрированный сервер берёт его напрямую). Поднимаете свой render distance —
  поднимаете и дальность видимости техники.
- **На выделенном сервере** это отдельная настройка `view-distance` в
  `server.properties`, клиентский render distance тут роли не играет сам по
  себе — его тоже стоит выставлять не меньше.
- **Рекомендация:** `view-distance=16`, `simulation-distance=8` в
  `server.properties` для выделенного сервера. На simulation-distance завязана
  область, где сущности вообще тикают (двигаются, живут) — дальше её ракета
  или беспилотник просто не заспавнится/не будет двигаться, сколько ни поднимай
  tracking range.
- Клиентский `renderDistance` стоит держать **не меньше** view-distance
  сервера — иначе сущность уже отслеживается сервером, но не попадает в
  скомпилированный участок рендера и всё равно не видна.

## 2. Встроенный дальний рендер SuperbWarfare (BVR)

У SBW уже есть рендер техники/снарядов за пределами обычной дальности
отслеживания — выключен по умолчанию. Включён в
`instance/defaultconfigs/superbwarfare-server.toml`, секция `[sync]`:

```toml
[sync]
	enable_render_synced_entities = true
	max_render_distance = 2048
	min_render_height = 128
```

Сервер и так рассылает эти данные синхронизации каждый тик независимо от
флага рендера — включение стоит дёшево, это чисто клиентская отрисовка.
`min_render_height = 128` специально держит порог выше типичного рельефа:
иначе далёкая наземная техника будет "висеть в воздухе" без подгруженной
земли под ней. Это в первую очередь работает для авиации на высоте; для
наземной техники эффект ограниченный по той же причине.

**Для уже существующих миров** эта правка в `defaultconfigs` новых миров не
трогает — нужно вручную поправить `saves/<мир>/serverconfig/superbwarfare-server.toml`.

## 3. Собственные ракеты Industry

У `combat_ballistic_missile` и `combat_interceptor` (`modules/industry`) была
встроенная ванильная отсечка рендера по размеру хитбокса — ракета пропадала
из вида на ~30-47 блоках, даже если tracking range позволял видеть дальше.
Исправлено: `shouldRenderAtSqrDistance` теперь всегда возвращает `true`, как у
родных снарядов SBW. Tracking range этих ракет и пусковой установки также
поднят (см. `CombatContent.java`), чтобы view-distance сервера оставался
единственным ограничением.

Авиационные ракеты (`modules/aviation`) — нативные сущности SBW, уже не
подвержены этой проблеме (их `shouldRenderAtSqrDistance` всегда `true` в
самом SBW).

## 4. Distant Horizons — не в комплекте

Distant Horizons рисует только рельеф/блоки на расстоянии, технику и ракеты
он не касается — их видимость целиком определяется пп. 1-3 выше. Это
опциональный личный клиентский мод (как на клиенте, так и на сервере), общий
набор модов проекта от него не зависит и не выигрывает в совместимости. Он не
добавлен в закреплённый `modpack.lock.json` — слишком дорог по диску/CPU
генерации (`maxGenerationRequestDistance` по умолчанию 4096) для совместного
сервера с физикой SBW и ИИ recruits одновременно, и это решение каждый
принимает для себя лично, а не как часть игровой сборки.

## 5. Предгенерация карты

Предгенерация конечной по размеру карты убирает **стоттер при генерации
новых чанков** (спайк CPU, когда игрок/самолёт впервые залетает в область).
Она не снимает стоимость самого тика/рендера уже загруженной области — это
по-прежнему определяется view-distance/simulation-distance выше, растущими
примерно как их радиус в квадрате.
