## Изменение поведения

Причина ухода AGM вверх — native loft: при дальности больше 30 блоков AGM
добавляет к высоте цели `0.4 * (distance - 30)`. Только для проверенного ручного
пуска добавлен persistent-маркер `frontierAircraftDirectAim`, отключающий этот
подъём. Каждая подвеска направляется к общей с пушкой точке HUD. У обычных AGM
маркер отсутствует и прежнее наведение сохраняется. Фиксированный pitch-offset
не используется. Готовность, magazine, heat, reload, урон и снаряды остаются
native; для пушки DSM сохраняется собственный `cannonRounds`.

Сервер проверяет первое препятствие, сектор и дальность без загрузки чанков.
Используется `SEEK_WEAPON_INFO`, соответствующий JSON ракеты, а не старые
параллельные поля SeekAngle/SeekRange. Отложенные выстрелы повторно проверяют
пилота, lease/epoch, выбранное оружие и готовность.

Каталог связывает модель, управление, умеренное демпфирование боковой скорости,
loadout и правило удаления после смерти. AircraftController/AircraftArmament дают
NPC доступ к существующему серверному контуру. Сам ИИ воздушного боя не добавлен.
AGM F-16 остаётся воздух–земля; для воздушного боя нужен отдельный compatible
entity-seeking loadout. Инструкция: [AIRCRAFT-EXTENSION-RU.md](../aviation/AIRCRAFT-EXTENSION-RU.md).
