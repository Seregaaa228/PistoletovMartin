# PIS-1: итоговая проверка 25 октября 2026

Изменения находятся в [PR #1](https://github.com/Seregaaa228/PistoletovMartin/pull/1).
Minecraft 1.20.1, Forge 47.4.0 и Java 17 сохранены; зависимости закреплены
в integration-libraries.lock.json. Старые native ID, сохранения и два combat overlay не менялись.

## Исправления

- Пресс читает уже загруженный LevelChunk: анимация больше не создаёт UNKNOWN tickets,
  мешавшие выгрузке чанка и продолжению ремонта.
- Тестовый launcher больше не обрезает общие native-библиотеки при запуске другого клиента.
  Неизменные файлы сохраняются; новые байты публикуются атомарной заменой inode.
  Прежний SIGSEGV совпал с перезаписью libglfw: вызов clock_gettime попал
  в исходное нерелокированное значение GOT. Обе регрессионные проверки сначала
  воспроизвели проблему старого кода, затем прошли после исправления.
- Compatibility Mixin исключает на dedicated server только три точные клиентские
  LDLib/Rhino bindings. Остальные bindings и весь клиентский путь сохранены.
  Чужие JAR и версии не изменялись; ошибки не скрываются фильтром журнала.
