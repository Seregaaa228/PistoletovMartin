# frontier-light-aviation 1.1.0

Для установленной сборки Minecraft 1.20.1 / Forge 47.4.0 / DeepStrike 0.9.0 / Superb Warfare 0.8.9.1.

Огонь двигателей Су-25, F-16 и J-10 использует штатный эффект Су-24. Он виден до 128 блоков; обычный дым — до 96. При недоступном штатном шейдере используется обычная частица огня Minecraft. У выключенного, пустого или повреждённого двигателя огня нет. Общий предел дыма и запасного огня — 16 запросов частиц за тик.

Игрок может атаковать свои, союзные и нейтральные цели и выбирать их для захвата. Ручные пуски Patriot и Iron Dome получают разрешение только через проверенный ручной ввод. Автоматические NPC сохраняют прежние правила, в том числе при онлайн-владельце или владельце на сиденье. Права владения, проверка сессии/радара/дальности/боеприпасов и серверный pvp=false сохраняются.

ID самолётов, модели, управление, боезапас, FE и сохранение существующих самолётов не меняются. Для получения используй творческую вкладку «Frontier · Авиация» либо /give @s frontier_aviation:su25, frontier_aviation:f16, frontier_aviation:j10. Новый предмет размещается с полной энергией; переупаковка сохраняет остаток.

Проверка: 282/282 функциональных и 6/6 после перезапуска мира; отдельный сервер, два настоящих TCP-клиента и повторный запуск сохранённого тестового мира. Подробности: server-acceptance.json, world-restart-acceptance.json и test-evidence/. Тестовый helper в игровую сборку не устанавливается.

На выделенном сервере и у всех игроков должны быть одинаковые версии обоих обновлённых JAR: frontier-light-aviation-1.1.0.jar и frontier-flamingo-launch-fix-1.3.0.jar. Для применения перезапусти Minecraft/сервер.

Старая версия сохранена в backup/. Для отката закрой игру, убери только frontier-light-aviation-1.1.0.jar и верни frontier-light-aviation-1.0.0.jar из backup/. Остальные моды и пользовательские миры установщик не меняет. Не оставляй две версии одного мода одновременно.
