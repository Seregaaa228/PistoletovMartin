# Промышленность Frontier 0.4.0

Сначала установи клиент по README-RU.txt. На сервере и у игроков должен совпадать набор модов.

## Как построить базу

1. Возьми КПК и нажми ПКМ по воздуху. Открой **«Заводы» → «Комплекты зданий»**. Кнопка **«Собрать»** покупает комплект за показанные железо, медь, редстоун и, для лаборатории, изумруды.
2. В разделе «Заводы» найми **строителя за 4 изумруда**. Рядом должно быть свободное место с твёрдой опорой.
3. Возьми комплект. Контур показывает размер площадки; поставь его ПКМ на свободную ровную землю. Комплект расходуется один раз. Стены и машины появятся по этапам, когда строитель дойдёт до площадки.
4. Если свободный строитель рядом, он назначается автоматически. Иначе открой объект через КПК и нажми **«Назначить строителя / нанять»**. На вкладке «Стройка» видны прогресс и причина паузы.
5. Сначала построй электростанцию и подстанцию, затем заводы и исследовательский центр. Объекты одного владельца автоматически соединяются в цепочку **станция → подстанция → потребители**, если расстояние каждого соединения не превышает 128 блоков. Уголь загружается в электростанцию через её планшет/склад.

| Объект | Рабочее время строителя |
|---|---:|
| Подстанция | 20 с |
| Завод дронов | 30 с |
| Оружейный завод | 30 с |
| Завод техники | 40 с |
| Исследовательский центр | 40 с |
| Электростанция | 45 с |
| Ракетный завод | 45 с |

Это время работы после подхода NPC при 20 TPS. Смерть/отсутствие назначенного строителя, препятствие, повреждённый этап или выгрузка площадки ставят работу на паузу. Прогресс сохраняется. По завершении строитель освобождается для следующего задания.

## Встроенные планшеты и исследования

ПКМ по небольшому экрану внутри здания открывает управление им. Для длинных списков открывается игровое окно: производство, склад, работники, ремонт. У лаборатории есть вкладка **«Исследования»**.

В исследовательском центре:

1. Подключи питание и нажми **«+ Учёный»** — нужен свободный рабочий или 8 изумрудов на найм.
2. Выбери технологию в списке, выполнив её предыдущие исследования.
3. Нажми **«Внести материалы»**, затем **«Начать исследование»**.

| Технология | Время | Изумруды / редстоун | Предыдущие технологии |
|---|---:|---:|---|
| Стрелковое вооружение | 90 с | 4 / 4 | — |
| Разведывательные БПЛА | 90 с | 4 / 8 | — |
| Ударные БПЛА | 150 с | 8 / 8 | Разведывательные БПЛА |
| Бронетехника | 180 с | 8 / 8 | Стрелковое вооружение |
| Базовое ПВО | 180 с | 8 / 12 | Разведывательные БПЛА |
| Ракетные технологии | 180 с | 12 / 12 | Ударные БПЛА |
| Авиация | 240 с | 12 / 16 | Бронетехника + ракетные технологии |
| Продвинутое ПВО | 240 с | 16 / 16 | Базовое ПВО + ракетные технологии |

Открытия общие для существующей страны. Без страны действует личный прогресс. На страну идёт одно исследование; два центра не удваивают скорость и не списывают стоимость повторно. Без питания, исправного центра или живого учёного рядом — пауза. Оплаченная очередь переживает перезапуск. Смена названия и столицы сохраняет открытия; выход из страны не переносит её знания игроку.

До изучения изделия видны как закрытые. Сервер проверяет изготовление, покупку в КПК и новое развёртывание техники/ПВО. Закрываемые военные изделия производятся на заводах: дублирующие рецепты, в том числе военные рецепты столов TaCZ, отключены. Уже имеющееся оружие можно использовать. OP в творческом режиме обходит технологические ограничения; проверять обычную прогрессию нужно в выживании.

## Повреждение и отмена стройки

«Ремонт этапов» восстанавливает только уже построенную часть; для автоматического ремонта нужен живой рабочий нужной роли и ремнабор во входных слотах. Чужие блоки и контейнеры не затираются. Зарезервированный ремнабор возвращается при отмене незавершённого объекта, даже если ремонт заблокирован.

До первого установленного блока отмена возвращает оплаченный строительный комплект. После начала стройки комплект израсходован. Сначала забери складские материалы. Сгенерированные строительные модули не выпадают как бесплатные ресурсы.

## Для владельца сервера

- Время строительства, бюджет размещения, время и цена исследований: `<мир>/serverconfig/frontier_industry-server.toml` (Forge создаёт файл при запуске).
- Дополнительные точные соответствия изделий технологиям: `config/frontier-industry-research-products.json`. Новые моды с собственными способами изготовления требуют отдельной интеграции.
- Старые здания V1/V2 сохраняют прежние размеры и планировку. Авторские новые здания появляются при новой стройке; существующие постройки автоматически не перестраиваются.
- NPC выполняют выданные задания. Самостоятельный выбор промышленной стратегии странами ИИ в это обновление не входит.
- Управление объектом и электросеть остаются у его владельца; общими для страны являются исследования.
