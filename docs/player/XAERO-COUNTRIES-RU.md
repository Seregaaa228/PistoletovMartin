# Страны на карте Xaero

`M` открывает обычную карту Xaero для просмотра. Слева находится панель «Страны»: слой территорий, список стран и флаг своей страны. Заголовок сворачивает панель, колесо над списком прокручивает его. Перемещение карты и масштабирование работают штатно. Изменения границ на обычной карте нет; старые входы карты Recruits тоже открывают Xaero для просмотра.

Для изменения контура лидер страны открывает **КПК → Страна → Границы на карте**. Откроется Xaero с уже включённым редактором:

- ЛКМ на карте добавляет точку; за существующую точку можно потянуть.
- ПКМ рядом с точкой удаляет её; Backspace удаляет последнюю.
- СКМ перемещает карту во время рисования, колесо меняет масштаб. Штатные кнопки Xaero остаются доступны.
- **Сохранить** / Enter отправляет контур серверу. Нужны минимум три точки, максимум 128; пересечения не допускаются.
- **Отмена** / Escape отбрасывает черновик. Закрытие карты или переход к другому измерению тоже отменяет черновик.
- **Сбросить**, затем **Сохранить** возвращает изображение по исходным владениям.
- **← КПК** возвращает в прежний КПК. После сохранения внутри этого сеанса доступна кнопка **Изменить контур**. Доступ к редактору не переносится в следующее обычное открытие карты на M.

После отправки ожидайте ответ сервера: повторное сохранение до ответа недоступно. Если за 10 секунд подтверждение не пришло, черновик остаётся в редакторе и его можно отправить снова. Ответы на предыдущие отправки не закрывают новый черновик. Можно вернуться в КПК, но выход не отменяет уже отправленный запрос. Для отправки контура КПК должен оставаться в одной из рук; права лидера проверяются сервером заново.

Контур меняет только изображение страны. Владения, захваты, защита блоков и стоимость территорий остаются у Recruits. Контуры Верхнего мира показываются только на его карте и сохраняются на сервере.

Граница проходит по граням блоков: диагонали превращаются в ступеньки с шагом **один блок**, а заливка повторяет тот же край. Это видно и при редактировании, и после сохранения; точки по-прежнему задают общую форму. При сильном отдалении неразличимые ступеньки объединяются для отрисовки; приближение возвращает шаг в один блок.

**Мой флаг** открывает пиксельный редактор с палитрой и заготовками. Изменять флаг может лидер; после закрытия редактора открывается прежняя карта.

При сохранении флага редактор ожидает серверного подтверждения. Если подтверждение не пришло, рисунок остаётся в открытом редакторе для повторной отправки. Закрытие окна во время ожидания не отменяет уже отправленное сохранение.

Tab показывает обычный список игроков. Перед именем участника страны появляется её флаг; игроки без страны остаются без значка. Сортировка, головы, пинг, счёт и режим наблюдателя сохраняют обычное поведение. Чат открывается на T.

Для ручной проверки используйте новый профиль внутри проекта и новый мир. Запуск подготовленного профиля:

```sh
python3 tools/run_map_client.py run-xaero-polished
```

После исправлений мультиплеера от 25 октября обновляйте **Nations и Industry на сервере и у всех игроков**. Собственные каналы используют версии `flags=2`, `borders=2`, `operations=3`; старые клиенты отклоняются при подключении. Существующие миры и native владения сохраняются. По последующей просьбе пользователя сборка проверена с двумя настоящими клиентами и выделенным сервером, включая полный перезапуск. Найденное зависание планировщика Recruits при остановке dedicated-server исправлено. Точные SHA256 и границы проверки: [отчёт](../testing/MULTIPLAYER-2026-10-25.md).
