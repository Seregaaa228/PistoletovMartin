# Инструкции для работы в этом проекте

Прочитайте README.md, BUILD-RU.md и CONTRIBUTING.md перед изменениями.
Работайте в этой папке проекта. Не используйте личный .minecraft и старые
каталоги чатов как место сборки или тестирования.

Сохраняйте Minecraft1.20.1/Forge47.4.0/Java17, native ID и форматы сохранений.
Используйте закреплённые зависимости. Не обновляйте их молча.

Не меняйте игровую механику в задаче на внешний вид. Не путайте новый заказ с
сохранённой оплаченной очередью. В тестах используйте отдельный свежий мир.

Две .class в modules/industry/preserved-combat являются точными принятыми
артефактами: соответствующие Java-файлы в архиве старее. Не убирайте overlay без
восстановления исходников и проверки боевой совместимости.

Сторонние моды и их лицензии сохраняются отдельно от собственных дополнений.
Не добавляйте в Git учётные данные, миры, серверные адреса или большие кэши.

## Рабочий порядок

Перед изменениями проверьте `git status --short` и существующий diff. Работайте
в отдельной ветке/worktree, не переносите и не перезаписывайте чужие незакоммиченные
изменения; ограничьте diff файлами своей задачи. Уже существующие чужие изменения
укажите в отчёте, не исправляя их молча.

Не обновляйте зависимости и lock-файлы молча. Native ID и форматы сохранений
меняйте только с совместимой миграцией и проверкой старого мира. Не удаляйте и не
заменяйте `modules/industry/preserved-combat` без восстановления точных исходников
и боевой проверки.

## Сетевые снимки Industry

Сетевые лимиты строк считайте в байтах UTF-8, а не в `String.length()`. JSON каждой
части каталога ограничен 262144 байтами (256 КиБ). Не смешивайте части разных
`catalogHash` и не выдавайте неполный набор за снимок: новый снимок применяется
атомарно только после сборки всех частей, прежний полный остаётся доступен до этого.
При refresh совпадающий `catalogHash` позволяет использовать собранный каталог;
неизвестный или изменившийся хэш требует полной передачи.

## Проверки перед передачей

Выполните команды из раздела «Проверка перед передачей» в README.md: проверку
профиля, standalone contract checks, Python unittest, ресурсы и offline-сборку
Industry, затем полную сборку. `./gradlew :industry:test` не заменяет standalone
checks. Для затронутого игрового поведения нужен реальный запуск в свежем мире;
reload/restart, выделенный сервер и два клиента проверяются отдельно и не считаются
выполненными по результатам компиляции или старым отчётам. Перед отчётом запустите
`git diff --check`, перечислите фактически выполненные проверки и невыполненные
игровые сценарии.
