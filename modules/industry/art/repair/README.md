# Пресс — исходники GeckoLib 4

Оригинальная модель Frontier Industry: press.bbmodel с вложенной текстурой и
ключами обеих анимаций. Формат Blockbench Bedrock; масштаб 16 единиц на блок.
Пресс помещается в прежний коллизионный объём detail_press, его поршень движется
только внутри рамы. Текстура 128×128, две кости.

Рабочий (frontier_industry:worker) больше не GeckoLib-модель: клиент рисует его
жителем (ванильный villager.png из игры: голова, лицо, нос) в нашей рабочей
одежде: каска, рубашка, перчатки, сигнальный жилет, пояс с инструментами,
брюки с наколенниками и ботинки — см. ../worker/worker_outfit.py.

Начальные ассеты пресса воспроизводятся стандартным Python без сторонних пакетов:

    python3 modules/industry/art/repair/export_assets.py

Скрипт восстанавливает исходную версию из своих числовых описаний. После правок
в Blockbench сохраните .bbmodel и экспортируйте geometry/animations/PNG в прежние
пути src/main/resources/assets/frontier_industry/{geo,animations,textures}.
Повторный запуск генератора перезапишет эти ручные правки исходной версией.

Серверный флаг анимации рабочего (SynchedEntityData) по-прежнему выбирает
состояние; клиент WorkerVillagerRenderer по нему поднимает сложенные руки
при ремонте и ничего не запускает сам. Пресс использует
animation.press.work и animation.press.stop по серверному флагу, который
появляется только при реальном продвижении производственного заказа. Его пакет
передаётся при переходе состояния; новый клиент получает флаг при загрузке чанка.

Для следующей анимации добавьте ключи в существующий .bbmodel/animation JSON,
объявите RawAnimation и выберите её в существующем контроллере. Новый рендерер
не нужен. Если состояние игровое, определите его на сервере, добавьте явный флаг
синхронизации и проверьте повторное подключение. Анимационные события не должны
тратить ресурсы, менять очередь или выдавать результат.

Существующий ID frontier_industry:worker, блок detail_press, его facing states
и старые пути OBJ/ресурсов сохранены. Только мировой пресс использует новый
GeoBlockRenderer; остальная архитектура и техника сохраняют свои рендереры.
Старому прессу в загруженном промышленном объекте v3 сервер добавляет отсутствующий
косметический BlockEntity, не заменяя блок и не трогая сохранённые запасы.
