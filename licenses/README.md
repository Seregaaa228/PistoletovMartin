В Arcade исходный LICENSE.txt содержит MIT, а mods.toml объявляет GPL-3.0-only. Оба файла сохранены, различие при переносе не исправлялось. Aviation и Missile Fix объявляют MIT в mods.toml, но отдельного LICENSE в переданных архивах не было; новая авторская лицензия за разработчиков не создавалась. Это учёт наблюдаемых объявлений, не проверка всех разрешений на распространение. Старые заметки прежнего экспорта сохранены в reference и не считаются актуальным списком.
